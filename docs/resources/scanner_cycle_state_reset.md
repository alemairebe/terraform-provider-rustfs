# rustfs_scanner_cycle_state_reset Resource

Run the scanner cycle-state reset (POST /rustfs/admin/v3/scanner/cycle-state/reset). Creating this resource clears the scanner's cycle-recovery bookkeeping and makes the next cycle scan the full namespace; it does not discard usage accounting. The action is one-shot: Read only echoes the recorded result, Delete is a no-op, and changing `triggers` runs the reset again. The provider retries a busy scanner leader lock a few times before failing. Scanner tuning stays in the `scanner` subsystem of `rustfs_config` or in the server environment.

## Example Usage

```terraform
# Break-glass scanner cycle-state reset. Creating this resource clears the
# scanner's cycle-recovery bookkeeping and makes the next cycle scan the full
# namespace. It does not discard usage accounting.
#
# The resource is an action, not managed state: Read only echoes the result and
# Delete is a no-op. Change a trigger when you deliberately want to run the
# reset again.
resource "rustfs_scanner_cycle_state_reset" "recover" {
  triggers = {
    reason = "cycle-recovery-required"
  }
}

output "scanner_cycle_reset" {
  value = {
    status = rustfs_scanner_cycle_state_reset.recover.status
    mode   = rustfs_scanner_cycle_state_reset.recover.mode
  }
}
```
