# rustfs_token_revocation Resource

Revoke a RustFS user's temporary (STS) access keys for one identity provider (POST /rustfs/admin/v3/revoke-tokens/{user_provider}).

**This action logs users out immediately.** Creating the resource deletes every STS credential `user` holds under `user_provider`; the next request signed with such a credential fails authentication. The revocation cannot be undone, so the resource has to name both the provider and the user: RustFS would otherwise default to the caller's own identity, and a provider-wide revocation is not what a typo should do.

The resource is an action, not managed state: Read only echoes the recorded result, Delete is a no-op, and changing `user_provider`, `user` or `triggers` replaces the resource and revokes again. Revocation is idempotent at the server: with no matching STS credentials left it reports zero revoked and succeeds.

## Example Usage

```terraform
# Revoke every STS credential bob holds under the OpenID provider. This logs bob
# out immediately and cannot be undone.
#
# The resource is an action, not managed state: Read only echoes the result and
# Delete is a no-op. Change triggers (or the user/provider) to revoke again.
resource "rustfs_token_revocation" "bob_openid" {
  user_provider = "openid"
  user          = "bob"

  triggers = {
    reason = "removed-identity-provider"
  }
}

output "revoked_count" {
  value = rustfs_token_revocation.bob_openid.revoked
}
```

## Schema

### Required

- `user` (String) Parent user whose STS credentials are revoked. It is required: omitting it would make the server revoke the caller's own tokens. Changing it revokes the new user and leaves the old revocation in place.
- `user_provider` (String) Identity provider whose STS credentials are revoked: `builtin`, `ldap` or `openid` (`openid` covers OIDC). Changing it revokes again.

### Optional

- `triggers` (Map of String) Arbitrary values that are not sent to the server. Change one to revoke again; without a change Terraform does not repeat the revocation.

### Read-Only

- `id` (String) `<user_provider>:<user>`.
- `revoked` (Number) Number of STS credentials the server reported deleting.
