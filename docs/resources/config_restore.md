# rustfs_config_restore Resource

Restore a stored server-config snapshot (PUT /rustfs/admin/v3/restore-config-history-kv). This is destructive: the snapshot replaces the whole live configuration, so it can undo an unrelated change another operator made after the snapshot was taken. RustFS saves the current configuration as a new history entry before applying the restore, so the restore itself can be undone through `rustfs_config_restore` and the entry that request created. The action is one-shot: Read only echoes the recorded result, Delete is a no-op, and changing `triggers` runs the same restore again. `restore_id` must name an entry from `rustfs_config_history`; a missing or legacy entry fails the apply and changes nothing.

## Example Usage

```terraform
# Destructive: the snapshot replaces the whole live configuration, so it can
# undo an unrelated change made after the snapshot was taken. confirm must
# repeat restore_id exactly.
#
# This is an action, not managed state: Read only echoes the recorded result
# and Delete is a no-op. Change a trigger when you deliberately want to run the
# same restore again; restore a newer entry to roll back this restore.
resource "rustfs_config_restore" "rollback" {
  restore_id = "4a1c9f4e-6d0b-4f5e-9f4c-2b7a1d8c3e10"
  confirm    = "4a1c9f4e-6d0b-4f5e-9f4c-2b7a1d8c3e10"

  triggers = {
    incident = "INC-1042"
  }
}
```

## Schema

### Required

- `confirm` (String) Must repeat `restore_id` exactly. Acknowledges that the restore overwrites the whole live configuration, not only the scope whose change is being undone.
- `restore_id` (String) Identifier of the history entry to restore, as returned by `rustfs_config_history`. Changing it restores a different snapshot.

### Optional

- `triggers` (Map of String) Arbitrary values that are not sent to the server. Change one to run the same restore again; without a change Terraform does not repeat it.

### Read-Only

- `id` (String) Resource identifier, the restored history entry.
- `restored_at` (String) When this resource last applied the restore, in RFC 3339.
