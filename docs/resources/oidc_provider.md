# rustfs_oidc_provider Resource

Manage one persisted OIDC identity provider used by RustFS Console single sign-on (`GET`/`PUT`/`DELETE /rustfs/admin/v3/oidc/config`).

Creating or updating the resource first runs OIDC discovery through `POST /rustfs/admin/v3/oidc/validate`, so an unreachable `config_url` or an invalid discovery document fails the apply before anything is persisted.

**Lockout risk:** deleting the last enabled provider can lock operators out of the RustFS Console. The provider emits a warning when it detects that condition.

**Secrets:** the server never returns `client_secret`. The provider keeps the configured value in state (marked sensitive) while the server reports the secret as configured, and removing it from the configuration does not clear it on the server. Destroy and recreate the provider to remove its secret.

## Example Usage

```terraform
resource "rustfs_oidc_provider" "keycloak" {
  id            = "keycloak"
  config_url    = "https://kc.example.com/realms/rustfs/.well-known/openid-configuration"
  client_id     = "rustfs"
  client_secret = var.oidc_client_secret
  display_name  = "Keycloak"
  scopes        = ["openid", "profile", "email"]
}

variable "oidc_client_secret" {
  type      = string
  sensitive = true
}

output "oidc_restart_required" {
  value = rustfs_oidc_provider.keycloak.restart_required
}
```

## Schema

### Required

- `client_id` (String) OAuth client id registered with the identity provider.
- `config_url` (String) OIDC discovery document URL, for example `https://kc.example.com/realms/rustfs/.well-known/openid-configuration`.
- `id` (String) Provider id (alphanumeric, underscore or hyphen). Changing this forces recreation.

### Optional

- `claim_name` (String) Claim that carries the user's policy groups. Defaults to `groups`.
- `claim_prefix` (String) Prefix stripped from policy claims. Defaults to an empty string.
- `client_secret` (String, Sensitive) OAuth client secret. The server never returns it; the configured value is kept in state while the server reports a secret is configured.
- `display_name` (String) Name shown on the Console login page. Defaults to the provider id.
- `email_claim` (String) Claim that carries the user's email address. Defaults to `email`.
- `enabled` (Boolean) Whether the provider is enabled for Console login. Defaults to `true`.
- `groups_claim` (String) Claim that carries group names. Defaults to `groups`.
- `hide_from_ui` (Boolean) Hide the provider from the Console login page. Defaults to `false`.
- `issuer` (String) Issuer expected in the discovery document. Null lets the server derive and verify it from `config_url`.
- `other_audiences` (List of String) Additional accepted token audiences. Defaults to an empty list.
- `redirect_uri` (String) Callback URL registered with the identity provider. Required when `redirect_uri_dynamic` is `false`.
- `redirect_uri_dynamic` (Boolean) Whether the server derives the callback URL from the request. Defaults to `true`.
- `role_policy` (String) Policy applied to every authenticated user. Defaults to an empty string.
- `roles_claim` (String) Claim that carries role names. Defaults to an empty string.
- `scopes` (List of String) OAuth scopes. Must include `openid`. Defaults to `["openid", "profile", "email"]`.
- `username_claim` (String) Claim that carries the user name. Defaults to `preferred_username`.

### Read-Only

- `client_secret_configured` (Boolean) Whether the server holds a client secret for this provider.
- `editable` (Boolean) Whether the server accepts changes for this provider. Environment-managed providers are not editable.
- `restart_required` (Boolean) Whether persisted changes differ from the configuration the running server loaded and a restart is required.
- `source` (String) Where the effective configuration comes from: `persisted` (managed here) or `env` (server environment variables).
