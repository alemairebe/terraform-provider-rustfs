# rustfs_tls_certificate Resource

Publish the leaf certificate the RustFS default listener serves.

Publishing is a whole-file replacement, not a patch, so changing either PEM replaces the resource and publishes the new pair. RustFS accepts the request only on its native TLS listener (`ssl = true`) and only when started with `RUSTFS_TLS_RELOAD_ENABLE=true` and `RUSTFS_TLS_PUBLISH_DIR` pointing at a private directory outside `RUSTFS_TLS_PATH`.

RustFS has no route that removes a published certificate. Destroying this resource therefore only removes it from Terraform state (with a warning); the server keeps serving the last published certificate until another publication replaces it or the server is restarted with different TLS material.

Import is not supported: the PEM pair is write-only and the server never returns it, so an imported resource could not describe the certificate it manages.

## Example Usage

```terraform
# Pass the PEM pair from your certificate source, for example
# certificate_pem = file("certs/api.crt") and key_pem = file("certs/api.key").
variable "certificate_pem" {
  description = "PEM-encoded leaf certificate chain to publish"
  type        = string
}

variable "key_pem" {
  description = "PEM-encoded private key for the leaf certificate"
  type        = string
  sensitive   = true
}

resource "rustfs_tls_certificate" "api" {
  certificate_pem = var.certificate_pem
  key_pem         = var.key_pem
}

output "tls_certificate_fingerprint" {
  value = rustfs_tls_certificate.api.certificate_fingerprint
}
```

## Schema

### Required

- `certificate_pem` (String) PEM-encoded leaf certificate chain to publish. The first certificate is the leaf; its subject alternative names must include every name the currently served certificate covers.
- `key_pem` (String, Sensitive) PEM-encoded private key for the leaf certificate. RustFS does not return it, so it is stored in Terraform state.

### Read-Only

- `certificate_fingerprint` (String) Lowercase SHA-256 fingerprint of the installed leaf certificate (DER).
- `id` (String) Identifier of the publication target, as reported by the server.
- `last_issuance_id` (String) Issuance ID of the publication the server installed. Null when the served certificate is the server's bootstrap material.
- `not_after_unix` (Number) Expiry of the installed leaf certificate as a Unix timestamp.
- `observed_certificate_fingerprint` (String) Fingerprint of the certificate the listener currently serves. Null until the listener has reloaded the publication.
- `resource_id` (String) Publication target the server reports (server-default).
- `schema_version` (String) Publication schema version the server installed (rustfs.tls-publish/v1alpha1).
- `target_revision` (String) Revision of the installed publication. A bootstrap certificate has a bootstrap-<fingerprint> revision until the first publication.
