# rustfs_rebalance Resource

Triggers a pool rebalancing operation in RustFS and reports its progress.

Creating the resource starts a rebalance. Refreshing mirrors `GET /rustfs/admin/v3/rebalance/status`: the trigger id, the overall state and the per-pool progress, usage and cleanup warnings. A server that does not implement the status route keeps the recorded trigger without failing the refresh.

Destroying the resource stops an in-flight rebalance through `POST /rustfs/admin/v3/rebalance/stop`. **Stopping does not move already relocated data back**: pools stay partially drained, and stopping a rebalance that already finished is a no-op. The status route is deployment-wide, so the resource only observes and stops the run it started (or the run recorded by the legacy fixed id); a rebalance started outside Terraform is reported and left alone. When the server does not implement the status or stop route, destroy warns and leaves any running rebalance in place.

## Example Usage

```terraform
# Start a pool rebalance. Refreshing reports the live run through `status` and
# `pools`; destroying the resource stops an in-flight rebalance.
#
# Stopping does not move already relocated data back: pools stay partially
# drained.
resource "rustfs_rebalance" "example" {}

output "rebalance_status" {
  value = rustfs_rebalance.example.status
}
```

## Schema

### Read-Only

- `id` (String) Rebalance trigger ID reported by the server.
- `pools` (Attributes List) Per-pool rebalance state, including inactive pools. (see [below for nested schema](#nestedatt--pools))
- `status` (String) Overall rebalance state derived from the per-pool report: `Started` while a pool is moving data or stopping, `Failed` when a pool failed, `Stopped` after a stop was requested, `Completed` when the run finished, or `None` when no run is recorded.
- `stop_propagation` (Attributes) How the last stop request propagated across the deployment. (see [below for nested schema](#nestedatt--stop_propagation))
- `stopped_at` (String) Time a stop was issued, as reported by the server in RFC 3339. Null while the rebalance has not been stopped.
