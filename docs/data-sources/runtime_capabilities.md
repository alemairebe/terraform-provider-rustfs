# rustfs_runtime_capabilities Data Source

Runtime capabilities advertised by the RustFS v4 admin API (GET /rustfs/admin/v4/runtime/capabilities). `storage_classes` is the versioned storage-class write contract: check `contract_version` before gating writes on `supported_write_classes`. The v4 admin API is a preview surface in RustFS 1.0.3; `json` keeps the full payload so a newer server can add fields without a provider release. A server that predates the v4 namespace answers `511 Upgrade Required`, which Terraform reports as a negotiation diagnostic naming the route and the server version.

## Example Usage

```terraform
data "rustfs_runtime_capabilities" "current" {}

output "storage_class_contract" {
  value = data.rustfs_runtime_capabilities.current.storage_classes
}

# Gate a write on the versioned contract rather than on a provider version.
locals {
  supports_reduced_redundancy = (
    data.rustfs_runtime_capabilities.current.storage_classes.contract_version >= 1 &&
    contains(
      data.rustfs_runtime_capabilities.current.storage_classes.supported_write_classes,
      "REDUCED_REDUNDANCY",
    )
  )
}
```
