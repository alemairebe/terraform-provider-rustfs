# rustfs_replication_mrf Data Source

Reads the failed-replication (most-recent-failure) backlog counters of a bucket. The counters come from the aggregate response shape, which carries no object names or version ids and only needs the narrow `GetReplicationMetrics` admin action; the default madmin stream enumerates object identities and needs `ReplicationDiff`. The durable ledger is cluster-shared, so the counters cover the whole cluster. This data source is read-only: MRF records are operational data, not configuration, and it never retries or drains them.

## Example Usage

```terraform
data "rustfs_replication_mrf" "photos" {
  bucket = "my-bucket"
}

output "failed_replication_count" {
  value = data.rustfs_replication_mrf.photos.total_failed_count
}

output "failed_replication_targets" {
  value = data.rustfs_replication_mrf.photos.targets
}
```

- `replication_configured` (Boolean) Whether the bucket has a replication configuration. When false the counters are zero and no backlog was read; the server reports ReplicationConfigurationNotFoundError.
- `runtime_stats_available` (Boolean) Whether runtime replication statistics were readable.
- `targets` (Attributes List) Per-target failed and durable backlog counters, sorted by ARN. (see [below for nested schema](#nestedatt--targets))
- `total_failed_count` (Number) Failed replication operations across every target.
- `total_failed_size` (Number) Bytes that failed to replicate across every target.
