# rustfs_bucket_on_demand_migration_status Data Source

Read the runtime status of a bucket's on-demand migration configuration (`GET /rustfs/admin/v3/on-demand-migration/{bucket}/status`).

**Per-node caveat:** this endpoint reports the node that answered the request. Counters, queue depth and breaker state are per-node runtime state, so in a distributed deployment query every node to build a cluster-wide picture. The saved configuration and `updated_at` are cluster-wide; the provider reads whichever node its endpoint resolves to.

Reads of the status endpoint keep working while the module switch is off, so a disabled deployment can still be inspected.

## Example Usage

```terraform
# The status endpoint reports the node that answered the request. Counters,
# queue depth and breaker state are per-node, so query every node in a
# distributed deployment.
data "rustfs_bucket_on_demand_migration_status" "photos" {
  bucket = "photos"
}

output "on_demand_migration_configured" {
  value = data.rustfs_bucket_on_demand_migration_status.photos.configured
}

output "on_demand_migration_breaker" {
  value = data.rustfs_bucket_on_demand_migration_status.photos.breaker
}
```
