# rustfs_batch_jobs Data Source

Lists the MinIO-compatible batch jobs RustFS reports. RustFS implements the batch-job admin surface without a job execution backend: `list-jobs` always answers with an empty list, and `describe-job` and `status-job` always report that the requested job does not exist. Job documents are exposed as the raw JSON the server returned (`jobs`, `job`, `status`) instead of an invented Terraform schema, because the MinIO batch-job payload is large, version-dependent, and not owned by this provider. This data source is read-only; job submission stays an `mc`/`rc` operation.

## Example Usage

```terraform
data "rustfs_batch_jobs" "all" {}

output "batch_jobs" {
  value = data.rustfs_batch_jobs.all.jobs
}

# Describe and read the status of one job. RustFS has no batch-job execution
# backend, so this reports found = false for every id; the raw documents are
# exposed when a server does implement the engine.
data "rustfs_batch_jobs" "replicate_job" {
  job_id = "example-job-id"
}

output "batch_job_found" {
  value = data.rustfs_batch_jobs.replicate_job.found
}
```

## Schema

### Optional

- `job_id` (String) Describe and read the status of one job by id. When set, `job`, `status` and `found` are populated. RustFS has no job execution backend, so a job id cannot exist and `found` is false rather than an error.
- `job_type` (String) Only list jobs of this type. The server recognises `replicate`, `keyrotate` and `expire`; leave unset to list every type.

### Read-Only

- `found` (Boolean) Whether the requested `job_id` exists; null when no `job_id` was given.
- `id` (String) Data source identifier, derived from the query.
- `job` (String) Raw JSON job definition returned by `describe-job`; null unless `job_id` is set and the job exists.
- `jobs` (List of String) Raw JSON document of every listed job, exactly as the server returned it.
- `json` (String) Raw JSON `list-jobs` response as returned by the RustFS admin API.
- `status` (String) Raw JSON job status returned by `status-job`; null unless `job_id` is set and the job exists.
