# rustfs_object_data_cache_stats Data Source

Statistics of the RustFS object data cache (GET /rustfs/admin/v3/object-data-cache/stats). A deployment without a cache reports mode `disabled` and zero counters. This data source only observes the cache; its tuning stays in the server configuration.

## Example Usage

```terraform
data "rustfs_object_data_cache_stats" "current" {}

output "object_data_cache" {
  value = {
    mode          = data.rustfs_object_data_cache_stats.current.mode
    disabled      = data.rustfs_object_data_cache_stats.current.disabled
    entries       = data.rustfs_object_data_cache_stats.current.entries
    hits          = data.rustfs_object_data_cache_stats.current.hits
    lookups       = data.rustfs_object_data_cache_stats.current.lookups
    invalidations = data.rustfs_object_data_cache_stats.current.invalidations
  }
}
```

### Read-Only

- `disabled` (Boolean) Whether the cache is disabled.
- `entries` (Number) Number of cached entries.
- `fills` (Number) Number of cache fills since startup.
- `hits` (Number) Number of cache hits since startup.
- `id` (String) Data source identifier.
- `inflight_fills` (Number) Number of fills currently in flight.
- `invalidations` (Number) Number of cache invalidations since startup.
- `json` (String) Raw JSON response as returned by the RustFS admin API.
- `lookups` (Number) Number of cache lookups since startup.
- `memory_pressure_events` (Number) Number of times memory pressure evicted entries.
- `mode` (String) Cache mode reported by the server, or `disabled` when no cache is initialized.
- `singleflight_joins` (Number) Number of lookups that joined an in-flight fill instead of starting one.
