# rustfs_extensions Data Source

Extension catalog and instances from the RustFS v4 admin API (GET /rustfs/admin/v4/extensions/catalog and GET /rustfs/admin/v4/extensions/instances). Both payloads are returned as the server's JSON verbatim so the provider does not invent a schema the server has not committed to. The v4 admin API is a preview surface; a server that predates it answers `511 Upgrade Required`.

## Example Usage

```terraform
data "rustfs_extensions" "current" {}

output "extension_catalog" {
  value = jsondecode(data.rustfs_extensions.current.catalog)
}

output "extension_instances" {
  value = jsondecode(data.rustfs_extensions.current.instances)
}
```
