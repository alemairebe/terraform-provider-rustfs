# rustfs_plugins Data Source

Plugin catalog and instances from the RustFS v4 admin API (GET /rustfs/admin/v4/plugins/catalog and GET /rustfs/admin/v4/plugins/instances). Both payloads are returned as the server's JSON verbatim: the v4 plugin schema is new and stays opaque so a newer server does not require a provider release. Secret values in instance configuration are redacted by the server. The v4 admin API is a preview surface; a server that predates it answers `511 Upgrade Required`.

## Example Usage

```terraform
data "rustfs_plugins" "current" {}

output "plugin_catalog" {
  value = jsondecode(data.rustfs_plugins.current.catalog)
}

output "plugin_instances" {
  value = jsondecode(data.rustfs_plugins.current.instances)
}
```
