# rustfs_kms_backup_status Data Source

Read whether the RustFS server can export a KMS backup bundle, and which bundle responsibility the configured backend can claim.

This reports identifiers, paths and readiness only; it never returns key material. A `false` value for `export_supported` means backup is disabled until the server's `RUSTFS_KMS_BACKUP_DIR`, `RUSTFS_KMS_BACKUP_KEK` and `RUSTFS_KMS_BACKUP_KEK_ID` are set.

## Example Usage

```terraform
data "rustfs_kms_backup_status" "current" {}

output "kms_backup_ready" {
  value = data.rustfs_kms_backup_status.current.export_supported
}
```
