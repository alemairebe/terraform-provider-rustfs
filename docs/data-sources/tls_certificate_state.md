# rustfs_tls_certificate_state Data Source

Read the TLS certificate the RustFS default listener serves, including the publication revision and fingerprints.

The route is only available on RustFS 1.0.2 or later, and only on the native TLS listener (`ssl = true`).

## Example Usage

```terraform
data "rustfs_tls_certificate_state" "current" {}

output "tls_certificate_fingerprint" {
  value = data.rustfs_tls_certificate_state.current.certificate_fingerprint
}

output "tls_certificate_not_after" {
  value = data.rustfs_tls_certificate_state.current.not_after_unix
}
```

## Schema

### Read-Only

- `certificate_fingerprint` (String) Lowercase SHA-256 fingerprint of the leaf certificate in the current publication (DER).
- `last_issuance_id` (String) Issuance ID of the current publication. Null while the server serves its bootstrap certificate.
- `not_after_unix` (Number) Expiry of the leaf certificate as a Unix timestamp.
- `observed_certificate_fingerprint` (String) Fingerprint of the certificate the listener currently serves. Null until the listener has reloaded a publication.
- `resource_id` (String) Publication target the server reports (server-default).
- `schema_version` (String) Publication schema version the server reports (rustfs.tls-publish/v1alpha1).
- `target_revision` (String) Revision of the current publication. A bootstrap certificate has a bootstrap-<fingerprint> revision until the first publication.
