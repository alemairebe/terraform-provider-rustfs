# rustfs_cluster_snapshot Data Source

Read-only cluster snapshot from the RustFS v4 admin API (GET /rustfs/admin/v4/cluster/snapshot). The snapshot is a large, deployment-shaped payload and is returned as raw JSON so the provider follows the server instead of pinning every field. The v4 admin API is a preview surface; a server that predates it answers `511 Upgrade Required`.

## Example Usage

```terraform
data "rustfs_cluster_snapshot" "current" {}

output "cluster_snapshot" {
  value = jsondecode(data.rustfs_cluster_snapshot.current.json)
}
```
