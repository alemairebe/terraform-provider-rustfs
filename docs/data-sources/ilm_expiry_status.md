# rustfs_ilm_expiry_status Data Source

Exposes the RustFS lifecycle expiry worker status: whether expiry is enabled, how fresh the scanner is, the expiry queue counters, maintenance control, data-movement pause and the scan catch-up estimate. Read-only; it never changes ILM state.

## Example Usage

```terraform
data "rustfs_ilm_expiry_status" "expiry" {}

output "expiry_enabled" {
  value = data.rustfs_ilm_expiry_status.expiry.enabled
}

output "expiry_queue" {
  value = data.rustfs_ilm_expiry_status.expiry.lifecycle_expiry
}
```
